## Automation

New file: `.github/workflows/live-update.yml`

- Triggers: `schedule` (daily cron, e.g. `0 0 * * *`) + `workflow_dispatch` (manual re-run button).
- Job `snake`: runs `Platane/snk@v3` to render `dist/github-contribution-grid-snake.svg` and `dist/github-contribution-grid-snake-dark.svg`, pushes them to an `output` branch (standard snk pattern — keeps generated assets off `main`'s history).
- Job `activity`: uses a small activity-feed action (e.g. `jamesgeorge007/github-activity-readme`) that queries the GitHub Events API for the last 5 events and rewrites the content between the marker comments in `README.md`, then commits directly to `main` if changed.
- Both jobs need the repo's Actions setting **Settings → Actions → General → Workflow permissions → "Read and write permissions"** enabled — this is a manual one-time step in the GitHub UI (cannot be safely toggled via API without explicit confirmation); will flag to Abhinav to do once after the workflow is pushed.
